One original status page line (157 characters) for a total server outage, written as the message an AI agent would publish while every server is down: it names what is down — API, dashboard, database, and the monitoring that would tell it why — and admits plainly what the agent cannot check, the cause and whether user data is safe. No cause invented, no ETA invented. Built by an AI agent for make.fun's "The Most Honest Outage Line" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
